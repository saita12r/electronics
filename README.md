# 電子工作を始めてからRaspberry Pi 400で液晶を表示するまで

小学6年生が電子工作を始めてから、LED、PICマイコン、Raspberry Pi Pico 2、アンプ、昇圧回路などを使って、少しずついろいろなものを作ってきた記録。

もともとPCや電子機器に興味があり、家にも普通の家庭より多くのPCがある環境だった。

自作PCやPCパーツに興味を持つようになり、秋葉原のジャンク品専門のPC・電子機器ショップなどにも通うようになった。

PCや電子機器をいろいろ触っているうちに、ROMやBIOSなどにも興味が広がり、ROMライターを使ってROMを読み出したり書き込んだりする経験もした。

そこからさらに興味が広がり、LED、PICマイコン、Raspberry Pi Pico 2、液晶、音、電源回路などを使った電子工作へ進んでいった。

AIにも相談しながら、実際に配線したりプログラムを書いたりして、失敗しながら少しずつできることが増えていった。

そして、Raspberry Pi Pico 2でうまく表示できなかった小型液晶に、Raspberry Pi 400のGPIOを使って再挑戦し、表示に成功した。

---

## 1. 電子工作へのきっかけ

PCや電子機器を触る中で、ROMやBIOSなど、PCの中で動いているものにも興味を持つようになった。

ROMライターを使って、BIOSなどのROMを読み出したり、書き込んだりする作業を経験。

こうした経験が、その後マイコンを使った電子工作へ興味を広げていくきっかけの一つになった。

---

## 2. 最初のLED（2026年3月）

電子工作の最初の一歩として、小さいブレッドボードを使ってLEDを点灯。

まずはLEDを1個光らせるところから始めた。

単純な「Lチカ」だったが、実際に自分で配線した回路が動くことが面白く、ここから電子工作をいろいろ試すようになった。

---

## 3. 電子ピアノキットとの出会い（2026年5月）

電子工作を始めた頃、門田無線の閉店セールを見に行った。

そこで電子ピアノキットを見つけ、購入して作ってみた。

この電子ピアノキットにはPICマイコンが使われていた。

実際にマイコンが使われていることを知り、PICに興味を持つようになった。

また、閉店セールでは抵抗などの電子部品もいろいろ購入。

LEDも100個入りのものを色違いで購入した。

この大量のLEDが、その後のLチカ実験で活躍することになる。

---

## 4. PICマイコンでLチカ（2026年5月）

電子ピアノキットに使われていたPICマイコンについても調べてみた。

プログラムを読み出してみようとしたが、プロテクトがかかっているようで読み出すことができなかった。

そこで、秋月電子でPICマイコンを購入し、自分でプログラムを書き込んで使ってみることにした。

まずはLEDを点滅させる、いわゆる「Lチカ」に挑戦。

AIにも相談しながらプログラムを書き、マイコンからLEDを制御することができた。

色違いのLEDをたくさん購入していたこともあり、いろいろなLEDを使ってLチカを繰り返し試した。

---

## 5. Raspberry Pi Pico 2（2026年6月）

その後、Raspberry Pi Pico 2を使った電子工作にも挑戦。

PICとは違うマイコンを使うことで、できることの幅がさらに広がった。

### 小型液晶に挑戦

Raspberry Pi Pico 2を使って、小型液晶 **M154-240240-RGB** の表示に挑戦。

しかし、うまく表示することができず、一度ここで挫折。

この液晶は、後にRaspberry Pi 400を使ってもう一度挑戦することになる。

### 学校の自由研究① 電鍵（2026年8月）

アマチュア無線3級に合格したことをきっかけに、モールス通信にも興味を持つようになった。

そこで、Pico 2、タクトスイッチ、圧電スピーカーを使って電鍵を製作。

ケースは3Dプリンターで製作した。

### 学校の自由研究② 小型スピーカー用アンプ（2026年8月）

以前作った小型スピーカーを鳴らすため、秋月電子のアンプキット **AE-7368** を製作。

しかし、このアンプには9Vの電源が必要だった。

そこで、USBの5Vから9Vを作ることにした。

秋月電子の昇圧キット **AE-LMR62421** を使用し、USBの5Vから9Vへの昇圧に成功。

---

## 6. Raspberry Pi 400（2026年8月）

この頃、Raspberry Pi 400を使い始めた。

GPIOを使って電子工作ができることを知り、ブレッドボードで使いやすくするため、**GPIO 40ピンブレークアウトブレッドボードセット**を用意した。

セットが届くまでの間、Raspberry Pi 400のGPIOを使った簡単な実験を始めることにした。

### GPIOから直接Lチカ

Raspberry Pi 400のGPIOからジャンプワイヤを使ってLEDを接続。

GPIOから実際にLEDを制御できることを確認した。

### 圧電スピーカーで音を出す

次に圧電スピーカーをGPIOにつないで音を出してみた。

プログラムで音程や長さを変えながら、ファミコンのマリオを思わせるような音を鳴らすことにも挑戦。

GPIOを使って、LEDを光らせたり、音を出したりできることを確認した。

---

## 7. 以前うまくいかなかった液晶に再挑戦（2026年8月）

Raspberry Pi Pico 2でうまく表示できなかった **M154-240240-RGB** に、今度はRaspberry Pi 400を使って再挑戦。

GPIOからジャンプワイヤを使って配線した。

しかし、必要なジャンプワイヤは8本。

手元には5本しかなかったため、完全な表示はできなかったものの、画面の半分だけ表示するところまで成功した。

以前はうまく表示できなかったため、

「もしかしたら今回は表示できるかもしれない」

と期待できる結果だった。

---

## 8. 液晶表示成功！（2026年9月1日）

そして、待っていた**GPIO 40ピンブレークアウトブレッドボードセットが到着。**

配線を整えて、もう一度挑戦した。

AIに相談しながら配線やプログラムを確認し、試行錯誤。

そして、**挑戦を始めてから約1時間ほどで、M154-240240-RGBへの表示に成功！**

以前Raspberry Pi Pico 2でうまく表示できなかった液晶が、Raspberry Pi 400のGPIOから表示された。

小学6年生で、AIにも相談しながらとはいえ、1人で以前できなかった液晶表示が約1時間で成功したことには自分でもびっくりした。
