# 電子工作を始めてからRaspberry Pi 400で液晶を表示するまで

小学6年生が電子工作を始めてから、LED、PICマイコン、Raspberry Pi Pico 2、アンプ、昇圧回路などを使って、少しずついろいろなものを作ってきた記録。

マイコンでLチカを始めた頃から、AIにも相談しながら、実際に配線したりプログラムを書いたりして試行錯誤してきた。

最初はLEDを1個光らせるところから始まり、失敗したり、うまくいかなかったりしながら、少しずつできることが増えていった。

そして最後は、以前PICマイコンで表示できなかった小型液晶に、Raspberry Pi 400のGPIOを使って再挑戦し、表示に成功した。

## 1. 最初のLED

まずは小さいブレッドボードを使ってLEDを点灯。

電子工作の最初の一歩として、LEDを実際に光らせてみた。

## 2. PICマイコンでLチカ

次にPICマイコンを使ってLEDを点滅させる、いわゆる「Lチカ」に挑戦。

AIにも相談しながらプログラムを書き、マイコンからLEDを制御することができた。

## 3. 小型液晶に挑戦

次にPICマイコンを使って、小型液晶 **M154-240240-RGB** の表示に挑戦。

しかし、うまく表示することができず、一度ここで挫折。

この液晶は、後に別の方法でもう一度挑戦することになる。

## 4. Raspberry Pi Pico 2

その後、Raspberry Pi Pico 2を購入。

### 学校の自由研究① 電鍵

アマチュア無線3級に合格したことをきっかけに、モールス通信にも興味を持つようになった。

そこで、Pico 2、タクトスイッチ、圧電スピーカーを使って電鍵を製作。

ケースは3Dプリンターで製作した。

### 学校の自由研究② 小型スピーカー用アンプ

以前作った小型スピーカーを鳴らすため、秋月電子のアンプキット **AE-7368** を製作。

しかし、このアンプには9Vの電源が必要だった。

電池を使うとすぐになくなってしまうため、USBの5Vから9Vを作ることにした。

秋月電子の昇圧キット **AE-LMR62421** を使用し、USBの5Vから9Vへの昇圧に成功。

## 5. Raspberry Pi 400

この頃、秋葉原でRaspberry Pi 400を入手。

師匠から、

> 「GPIOを使って液晶を表示してみよう」

という宿題をもらった。

そこでGPIOをブレッドボードで使いやすくするため、**GPIO 40ピンブレークアウトブレッドボードセットを発注。**

セットが届くまでの間、Raspberry Pi 400のGPIOを使った簡単な実験を始めることにした。

### GPIOから直接Lチカ

まずはRaspberry Pi 400のGPIOからジャンパーケーブルを直接つないでLEDを点灯。

GPIOから実際にLEDを制御できることを確認した。

### 圧電スピーカーで音を出す

次に圧電スピーカーをGPIOにつないで音を出してみた。

プログラムで音程や長さを変えながら、ファミコンのマリオを思わせるような音を鳴らすことにも挑戦。

GPIOで「光らせる」だけでなく、「音を出す」こともできることを確認した。

## 6. 以前挫折した液晶に再挑戦

40ピンブレークアウトブレッドボードセットが届く前に、以前PICマイコンで表示できなかった **M154-240240-RGB** に再挑戦。

ジャンパーケーブルを使って配線したが、必要なケーブルは8本。

手元には5本しかなかったため、完全な表示はできなかったものの、画面の半分だけ表示するところまで成功した。

以前はまったく表示できなかったため、「もしかしたら今回は表示できるかもしれない」と期待が持てる結果だった。

## 7. 液晶表示成功！

そして、待っていた**GPIO 40ピンブレークアウトブレッドボードセットが到着。**

配線を整えて、もう一度挑戦した。

AIに相談しながら配線やプログラムを確認し、試行錯誤。

そして、**挑戦を始めてから約1時間ほどで、M154-240240-RGBへの表示に成功！**

以前PICマイコンで挑戦して表示できなかった液晶が、Raspberry Pi 400のGPIOから表示された。

小学6年生で、AIにも相談しながらとはいえ、以前できなかった液晶表示が約1時間で成功したことには自分でもびっくりした。

最初はLEDを1個光らせるところから始まった電子工作が、マイコン、液晶、音、無線、電源回路へと少しずつ広がっていった。

これからも、失敗したものも含めて、実際に作ったものを記録していく。
